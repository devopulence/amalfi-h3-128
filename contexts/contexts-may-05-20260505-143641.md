Stock H3 was always technically wrong but always benign (`_ipow(7,15) = 4.7e12` squared = 2.2e25 still fits a double range but signed int64 overflows). v0.2.0 ext-res unmasks this. 3. **Single-platform round-trip is bit-deterministic on macOS Apple libm.** Item 3's measurement (1000 g_in × 23 resolutions, 0 rad delta everywhere) confirms that within-platform tests can rely on `h1 == h2` for cell-index equality, which then gives `g1 == g2` for free. Cross-platform variability (the actual purpose of `latlng_within_tolerance`) is structural — same g_in may produce different h1 on glibc vs Apple libm. Calibration against actual cross-platform deltas requires either a fixed-dataset cross-platform test or a CI-side measurement harness; both are deferred.

4. **`.env` near-miss reflagged.** System reminder during item 4 explicitly noted `/Users/johndesposito/amalfi_work/amalfi-h3-128/.env` contains `GITHUB_PAT`. Each commit in this session used named-file `git add` only (never `-A`, never `.`). Continue the discipline.
